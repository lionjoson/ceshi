# float optional dictionary resources

These data files contain open dictionary content only. No App, audio, subtitles, user queries, device data, account information or website is included.

Per-language sense indexes are extracted without adding meanings from the existing float multilingual index. They retain English source entry IDs, part of speech and explicit translation senses. Each target-language resource contains output words only for that target and normalized input lookup keys for all supported source languages. Lookup keys do not add new definitions. Cross-language matches must remain within the exact same sense ID. Chinese Simplified/Traditional share one resource.

Source: English Wiktionary contributors, Kaikki/Wiktextract/Tatu Ylonen, 2026-10-01 dump.
Bulk source: https://kaikki.org/dictionary/English/kaikki.org-dictionary-English.jsonl
Entry contribution histories: https://en.wiktionary.org/wiki/<word>?action=history

The chinese-en archive combines CC-CEDICT (MDBG, https://cc-cedict.org/wiki/) and WikDict (Karl Bartel/DBnary), CC BY-SA 4.0; lookup aliases, classifier separation and indexing are modifications. The Kaikki direction archives select and reverse existing translations; they do not contain generated definitions.
